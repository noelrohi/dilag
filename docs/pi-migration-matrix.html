Research Read

Pi has useful building blocks, but it does not expose an OpenCode-compatible HTTP server. Treat this as an adapter migration, not a package swap.

Pi capability

SDK embedding

@earendil-works/pi-coding-agent exports createAgentSession, createAgentSessionRuntime, AuthStorage, ModelRegistry, and SessionManager. This is the cleanest Electron-main integration path.

Fallback path

RPC mode

pi --mode rpc streams strict JSONL over stdio with prompt, state, model, session, compaction, bash, and extension UI commands. Good for process isolation, heavier for renderer-facing state.

Main gap

No OpenCode HTTP API

Dilag currently calls sdk.session.*, sdk.provider.list, sdk.question.*, and sdk.global.event. Pi events and session operations need a translation layer.
